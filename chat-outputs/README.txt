CHAT OUTPUT ARCHIVE
===================

This folder stores study summaries harvested from Spanish-learning chats.

Each file is a learning-history artifact, not merely a transcript summary.

NAMING
------
YYYY-MM-DD_short-topic.txt

REQUIRED SECTIONS
-----------------
CHAT PURPOSE
PHRASES LEARNED
LEARNER ATTEMPTS WORTH PRESERVING
GRAMMAR EXTRACTED
VERBS + TENSES
VOCABULARY WEBS
SYNTAX PATTERNS
DICTION / REGISTER
ETYMOLOGY TARGETS
POETRY / LITERARY BRIDGES
COMMON ERRORS OR OPEN QUESTIONS
TINY REVIEW SET
CONCEPT GRAPH EDGES

SUMMARY RULES
-------------
- Summarize grammar actually encountered in the chat.
- Preserve why the learner needed the language.
- Do not turn every chat into a comprehensive grammar lesson.
- When the learner guessed a form, preserve the attempt when it helps expose the underlying pattern.
- Distinguish correction from stylistic alternative.
- Mark uncertain etymology or regional claims for research.
- Reuse concept IDs/names from study-system/CONCEPT_GRAPH.txt when possible.
- Add short poetry examples only when they genuinely illuminate the grammar and copyright rules permit them.

The archive is chronological evidence. The concept graph is the cross-chat map.
