# 05 Verbs Today

Just the forms you'll actually use on Day 1.

| Verb | yo | usted / él / ella | Use it for |
|---|---|---|---|
| **poder** (can) | puedo | puede | polite requests |
| **ir** (go) | voy | va | destinations |
| **tener** (have) | tengo | tiene | possessions, age, hunger |
| **estar** (be — state) | estoy | está | location, mood |
| **ser** (be — identity) | soy | es | who/what you are |
| **querer** (want) | quiero | quiere | ordering, asking |
| **necesitar** (need) | necesito | necesita | bigger asks |
| **buscar** (look for) | busco | busca | finding things |
| **llevar** (carry/take) | llevo | lleva | "I have with me" |
| **hablar** (speak) | hablo | habla | "more slowly please" |

## Mini-patterns

- *¿Puede + [infinitive]?* — polite request. *¿Puede repetir?*
- *Voy a + [place].* — destination. *Voy a este hotel.*
- *Tengo + [noun].* — possession. *Tengo mi pasaporte.*
- *Estoy + [adjective].* — temporary state. *Estoy perdido.*
- *Soy + [identity].* — *Soy turista. Soy de Estados Unidos.*
- *Quiero + [noun or infinitive].* — *Quiero un taxi. Quiero pagar.*
- *Necesito + [noun].* — *Necesito ayuda.*
- *Busco + [noun].* — *Busco mi equipaje.* (no *por*)
- *Llevo + [noun].* — *Llevo una mochila.*

## Voice note

Don't worry about conjugating beyond *yo* and *usted* today. Those two forms cover most Day 1 conversations.
