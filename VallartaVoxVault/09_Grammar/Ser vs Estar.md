# Ser vs Estar

Two verbs that both mean *to be*. The most useful rule is not "permanent vs temporary" — that one breaks fast.

## The working rule

- **Ser** = identity / definition / what something *is*.
- **Estar** = state / location / how something currently *is*.

## Test sentences

| Spanish | Verb | Why |
|---|---|---|
| Soy de Los Ángeles. | ser | identity / origin |
| Estoy en Puerto Vallarta. | estar | location |
| Soy turista. | ser | role / identity |
| Estoy cansado. | estar | current state |
| El café es caliente *(by nature)* | ser | defining quality |
| El café está caliente *(right now)* | estar | current state |
| Soy aburrido. | ser | *I am boring* |
| Estoy aburrido. | estar | *I am bored* |

## The trap

*Soy aburrido* vs *estoy aburrido* — same English, very different Spanish.

## Day 1 sentences using each

- ser: *Soy de Estados Unidos. Soy turista. El hotel es nuevo.*
- estar: *Estoy perdido. Estoy aprendiendo. El taxi está afuera.*

## Voice note

When in doubt, *estar* for how you feel right now, *ser* for who you are.
