# Core Verbs

The six that carry Day 1. Memorize the `yo` and `usted/él/ella` forms first.

| Verb | yo | usted | Use it for |
|---|---|---|---|
| **ser** | soy | es | identity, origin, definition |
| **estar** | estoy | está | location, current state, progressive |
| **tener** | tengo | tiene | possession, age, hunger, fear |
| **ir** | voy | va | destination (`voy a + [place]`) |
| **poder** | puedo | puede | polite request (`¿Puede + infinitive?`) |
| **querer** | quiero | quiere | ordering, asking |

Bonus, very useful Day 1:

| Verb | yo | usted | Use it for |
|---|---|---|---|
| **hacer** | hago | hace | making, doing (also weather: *hace calor*) |
| **decir** | digo | dice | saying, telling |
| **saber** | sé | sabe | knowing facts (vs **conocer** = knowing people/places) |
| **ver** | veo | ve | seeing |
| **dar** | doy | da | giving |
| **venir** | vengo | viene | coming |

## Patterns these unlock

- *¿Puede + [infinitive]?* → polite request
- *Voy a + [place]* → destination
- *Tengo + [noun]* → possession
- *Quiero + [noun / infinitive]* → desire
- *Hace + [time period]* → "ago" (*hace dos semanas* = two weeks ago)
