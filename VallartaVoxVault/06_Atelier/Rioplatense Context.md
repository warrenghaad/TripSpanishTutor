# Rioplatense Context

A reference page so the workbook can hold both Mexican Spanish and Rioplatense without confusing them.

## The big features

| Feature | Rioplatense | Mexican / neutral |
|---|---|---|
| 2nd person singular | *vos* | *tú* |
| Verb with *vos* | *vos tenés, sos, podés* | *tú tienes, eres, puedes* |
| *ll* / *y* sound | sh / zh (*calle* → "ká-sheh") | y (*calle* → "ká-yeh") |
| Intonation | sing-song, Italian-influenced | flatter |
| Slang | lunfardo (*che*, *boludo*, *laburo*) | mexicanismos (*chido*, *mande*, *ahorita*) |
| Common imperative | *tené, mirá, vení* | *ten, mira, ven* |

## When this matters

- Reading Borges, Cortázar, anything Argentine.
- Listening to tango lyrics, Argentine music, films from Buenos Aires.
- *Never* on Day 1 in PVR.

## When this is a trap

If you slip into *vos* in Mexico, no one will be confused — but it'll mark you as "not from here." Save *vos* for Borges nights.
