# Music Guitar Jazz

Phrases that open the music conversation in Spanish.

## Opening lines

> Toco guitarra.

> Me gusta el jazz, especialmente el espacio entre las notas.

> Más que la melodía, me gusta el silencio.

## Vocabulary

| Spanish | English |
|---|---|
| la guitarra | guitar |
| la cuerda | string |
| el traste | fret |
| el acorde | chord |
| la nota | note |
| el silencio | silence / rest |
| el ritmo | rhythm |
| improvisar | to improvise |
| ensayar | to rehearse |
| tocar | to play (an instrument) |
| sonar | to sound |

## Pattern

- *Me gusta cómo + [verb].* — *Me gusta cómo suena.* / *Me gusta cómo improvisa.*

## Voice note

This page is permission to talk about music in Spanish without sounding like a textbook.
