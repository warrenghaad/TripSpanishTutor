# Sentence Grower

Take a tiny seed sentence. Grow it one move at a time. The exercise that builds voice without grammar drills.

## How it works

1. Start with a 3-word sentence.
2. Add one piece per round: a place, a time, a reason, a feeling, a contrast.
3. Don't worry about perfection — worry about meaning surviving each round.

## Example

Round 1: *Toco guitarra.*
Round 2: *Toco guitarra en la noche.*
Round 3: *Toco guitarra en la noche cuando hay silencio.*
Round 4: *Toco guitarra en la noche cuando hay silencio, no para sonar bonito.*
Round 5: *Toco guitarra en la noche cuando hay silencio, no para sonar bonito sino para escucharlo.*

## Day 1 seeds

- *Voy al hotel.*
- *Tengo una pregunta.*
- *Estoy aprendiendo.*

Pick one and grow it on the plane.

## Voice note

This exercise replaces *"how do I say X?"* with *"what's the next thing I can add?"* — which is the same skill native speakers use when they're tired.
