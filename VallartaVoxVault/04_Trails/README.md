# 04 Trails

Saved spelunks — sequences of thinking from the app, desktop, or a conversation. A trail has a beginning, a turn, and an end.

## Naming

`YYYY-MM-DD Trail — short slug.md`

## What a trail note has

- starting question
- turns (each labeled with what shifted)
- where it ended (or where it's still going)
- what it produced: phrase / pattern / saved question / new trail

## Example trails

- A word you chased through three meanings.
- A grammar pattern you only saw because you mis-said it.
- A literary line that opened into a Mexican context.
