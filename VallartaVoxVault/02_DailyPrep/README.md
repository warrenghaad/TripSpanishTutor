# 02 Daily Prep

Pre-day briefings, generated by the Atelier or written by hand. One file per day.

## Naming

`YYYY-MM-DD Prep.md`

## What a prep note has

- the day's intent (one sentence)
- 5–10 phrases scoped to today
- 1 voice phrase
- 1 listening phrase
- 1 grammar pattern in use today
- a Bear-shortcut-ready capture stub
