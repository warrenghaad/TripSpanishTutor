# The offline app should answer in three levels

This is important. It keeps the app honest.

## Level 1: Direct offline answer

For known travel/grammar cards.

Example:

> “Where is the gate?”

App returns:

```txt
¿Dónde está la puerta?

Literal:
Where is the door/gate?

Grammar:
Dónde = where
está = is, from estar, used for location
la puerta = the gate, feminine noun

Practice:
Replace la puerta with el baño, la salida, el mostrador.
```

## Level 2: Guided offline scaffold

For Borges questions or book questions.

Example:

> “What is this Borges line doing?”

App returns:

```txt
Offline reading scaffold:

1. Find the main verb.
2. Identify the subject.
3. Mark the image: mirror, labyrinth, book, shadow, tiger, knife, street, dream.
4. Ask whether the line is about time, identity, memory, fate, or perception.
5. Save the line/question for online interpretation.

Practice:
Write one sentence using the same verb structure with an airport noun.
```

## Level 3: Save for LLM

For deep interpretation.

Example:

> “Is Borges using this as a Neoplatonic metaphor?”

App returns:

```txt
Saved for online LLM review.

Offline context:
This question likely belongs to:
- literary philosophy
- metaphor
- Borges motif
- ontology / appearance / reality

When online, ask:
"Explain this Borges line through Neoplatonism, mirrors, and Spanish grammar."
```

This is the right behavior. The app does not hallucinate. It catches the butterfly and pins the note.
