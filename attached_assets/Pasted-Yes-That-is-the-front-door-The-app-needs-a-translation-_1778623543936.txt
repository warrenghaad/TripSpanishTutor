# Core workflow

## 1. User enters text

Could be English or Spanish:

```txt
I am tired, but I want to write.
```

or:

```txt
Estoy cansado, pero quiero escribir.
```

## 2. App gives translation

```txt
Estoy cansado, pero quiero escribir.
```

## 3. App breaks it down

```txt
Estoy = I am, from estar
cansado = tired
pero = but
quiero = I want
escribir = to write
```

## 4. App gives sentence-growth options

```txt
Estoy cansado, pero quiero escribir algo pequeño.
Estoy cansado, pero quiero escribir sobre mi día.
Estoy cansado, pero mañana escribiré más.
```

## 5. App turns it into chat

The user taps:

```txt
Talk about this
```

Then the chat opens with context already loaded:

```txt
You translated: “I am tired, but I want to write.”
Spanish: “Estoy cansado, pero quiero escribir.”
Goal: help me talk about my day and grow this sentence.
```

Now the chat can ask:

```txt
¿Qué quieres escribir?
¿Sobre tu día?
¿Sobre un poema?
¿Sobre cómo te sientes?
```

The translation becomes a doorway, not a receipt.

```json

  "source_language": "en",

      "note": "adjective; masculine singular form"

    {
      "token": "despierto",
```

# “Turn into chat” behavior

When the user taps **Chat about this**, the app should not open a blank chat. It should open a seeded conversation.

## Chat seed object

```json
{
  "conversation_type": "translation_followup",
  "source_text": "I feel strange but awake today.",
  "translation": "Hoy me siento extraño pero despierto.",
  "learner_goal": "Help me say this naturally and grow it into Spanish journal sentences.",
  "suggested_questions": [
    "Why is it me siento instead of siento?",
    "How do I make this feminine?",
    "How do I say this in the past?",
    "How do I say this in the future?",
    "Can we make it more poetic?",
    "Can we make it simpler?"
  ]
}
```

Then the chat response can begin:

```txt
Good sentence. The core is “me siento,” which means “I feel.”

You can grow it three ways:

1. Add reason:
   Hoy me siento extraño pero despierto porque dormí poco.

2. Add place:
   Hoy me siento extraño pero despierto en el aeropuerto.

3. Add future:
   Mañana voy a escribir sobre esto.
```

That is the app teaching Spanish through your own sentence.

# Offline behavior

This needs two tiers.

## Online mode

When online:

```txt
User enters text
→ LLM/API translates
→ LLM explains grammar
→ user can chat
→ save result locally
```

## Offline mode

When offline:

```txt
User enters text
→ app saves it as a queued translation
→ app checks local phrase/grammar packs
→ app offers partial help if possible
→ full translation waits for online mode
```

Example offline response:

```txt
Saved for translation when online.

I can still help with known patterns:

“I feel...” often becomes:
Me siento...

Examples:
Me siento cansado.
Me siento nervioso.
Me siento perdido.
Me siento tranquilo.
```

So the app remains useful but honest.

Do not fake full offline LLM translation unless you actually bundle a local model later.

# Why this is the right move

Because translation gives you immediate utility, but the project’s soul is still sentence growth.

A normal translator says:

```txt
Here is the Spanish.
Goodbye.
```

Your app should say:

```txt
Here is the Spanish.
Here is what it is doing.
Here is how to make it yours.
Here is how to ask about it.
Here is how to write tomorrow from it.
```

That is the difference.

Translation is the doorway.
Conversation is the room.
Journal is the memory.
Practice is the muscle.
Borges is one stained-glass window. 🪟
