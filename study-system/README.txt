TRIPSPANISHTUTOR STUDY SYSTEM
=============================

PURPOSE
-------
This folder is the human-readable study layer for TripSpanishTutor / Vallarta Voz.
It turns phrases from travel, conversation, personal reflection, and literature into reusable grammar objects instead of isolated memorized sentences.

The core learning loop is:

PHRASE -> MEANING -> SYNTAX -> VERB/TENSE -> DICTION -> ETYMOLOGY -> VARIATIONS -> CONCEPT LINKS -> PRACTICE -> SAVE

Every phrase should eventually answer:
1. What does it mean literally?
2. What does it mean naturally?
3. What grammatical skeleton makes it work?
4. Which verbs are used, and what tense/mood/person are they in?
5. What vocabulary can be substituted without breaking the structure?
6. Why was this diction chosen instead of a nearby alternative?
7. What useful etymological roots or word families make it easier to remember?
8. Which other grammar concepts does it connect to?
9. How can the learner transform it once, immediately?
10. Where did the phrase come from: airport, small talk, reflection, poetry, etc.?

FILES
-----
GRAMMAR_STUDY_SYSTEM.txt
  Canonical template for turning any suggested phrase into a study document.

CONCEPT_GRAPH.txt
  Human-readable concept graph connecting grammar, vocabulary, situations, and literary motifs.

PHASED_ROLLOUT.txt
  Build sequence so the study system grows without requiring a huge database first.

../chat-outputs/
  Archive for summaries derived from individual ChatGPT conversations. Each chat summary should record grammar actually encountered, useful vocabulary, mistakes, corrections, and concepts that should feed the graph.

DESIGN RULES
------------
- Plain UTF-8 text is the canonical human-readable format.
- JSON may later mirror these files for app retrieval, but the text files remain understandable without tooling.
- Do not teach phrases as atomic units when a reusable structure can be exposed.
- Prefer vocabulary webs over giant word lists.
- Preserve the learner's actual voice and interests.
- Literature is one learning laboratory, not the whole curriculum.
- Poetry examples should scaffold grammar and imagery without reproducing long copyrighted passages.
- Etymology must carry a confidence label. If uncertain, mark it RESEARCH rather than inventing a story.
- Regional usage should be marked when relevant, especially Mexican Spanish versus neutral or Rioplatense usage.
- Every grammar note should lead to at least one usable transformation.
