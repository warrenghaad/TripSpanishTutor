GRAPH GROWTH RULE
-----------------
When a new phrase is learned:
1. Add the PHRASE node.
2. Link its situation and communicative function.
3. Link each important verb.
4. Link tense and mood.
5. Link syntax pattern.
6. Link vocabulary substitutions.
7. Add etymology/word-family links only when supported.
8. Link literary motif only when genuinely illuminating.
9. Link the source CHAT.
10. Add one PRACTICE_MOVE.

The graph should reveal repeated structures. If ten phrases all use PODER + INFINITIVE, the learner should be shown that family as a concept, not asked to memorize ten unrelated strings.
